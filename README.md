# 🏡 Zenvia Living (Project)

**Zenvia Living** is a full-stack accommodation platform where users can discover and list **rooms, villas, and homes** in their own country or abroad.

## 🚀 Live Demo

[Zenvia Living](https://zenvia-living-project.onrender.com/listings/)

## ✨ Features

- 🔍 Browse and search available properties
- 🏠 List rooms, villas, and homes
- 👤 User authentication and authorization
- 📍 Property details and locations through (Map)
- 🖼️ Property image uploads
- ⭐ Reviews and ratings
- 🔐 Secure JWT-based authentication
- ☁️ MongoDB Atlas database

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript, EJS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT
- **File Uploads:** Multer
- **Deployment:** Render
- **MAP:** Map API used -> to display locations

## ⚙️ Installation

```bash
git clone https://github.com/chauhanbibek100/Zenvia-Living.git
cd Zenvia-Living
npm install
npm start
```

Create a `.env` file and add your required environment variables before running the application.

## 🎯 Purpose

Zenvia Living aims to make finding and listing accommodations **simple, accessible, and convenient** for travelers, students, families, and property owners.
